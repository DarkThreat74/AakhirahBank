# Aakhirah Bank

A mobile-first Islamic charity tracker app. Every dollar donated is a "deposit" into your account in the hereafter.

## Prerequisites
- Node.js
- npm
- Expo CLI (`npm install -g expo-cli`)

## Getting Started

1. Install dependencies
```bash
npm install
```

2. Start the Expo development server
```bash
npx expo start
```

## Android APK Build

To build an Android APK via EAS:

1. Install EAS CLI if you haven't:
```bash
npm install -g eas-cli
```

2. Build the APK profiling:
```bash
eas build -p android --profile apk
```

Then download the APK from the link provided in your terminal.
